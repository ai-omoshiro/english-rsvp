このツールについて

English RSVP は、英文を意味のかたまり（チャンク）ごとに画面の中央へ1つずつ表示し、英語の語順のままの日本語訳を添えて、英語を前から順に理解する（直読直解）練習をするための無料のツールです。

使い方のこつ

  • 左上のボタンで教材（例文・表現・ストーリー・単語帳）を選び、画面をタップすると再生します。
  • 慣れてきたら「英語のみ」や「だんだん速く」で、訳なし・速めの表示に挑戦してください。
  • 「理解チェック」で「あやしい」「わからなかった」を選んだ文には苦手マークが付きます。「苦手だけ再生」で復習できます。
  • iPhone で読み上げの音が出ないときは、音量と消音モードを確かめてください。
  • Safari の共有メニューから「ホーム画面に追加」すると、アプリのように使えます。

データとプライバシー

  • 設定・苦手マーク・学習記録・追加した文は、お使いの端末のブラウザの中だけに保存されます。このツールが外部に送信することはありません。アクセス解析や広告も使っていません。
  • ブラウザの履歴やサイトのデータを消すと、保存した内容も消えます。
  • 読み上げはブラウザに入っている音声を使います。ブラウザによっては（Chrome の「Google」の声など）、読み上げる英文がブラウザの提供元のサーバーで処理されることがあります。
  • このページは GitHub Pages で配信しています。ページの配信にともなう記録は GitHub が管理しています。

例文について

  • 例文・物語・単語帳は、AI（Claude）の支援を受けて作成しました。ネイティブスピーカーの確認は受けていません。不自然な点や誤りに気づいたら、教えていただけると助かります。
  • 名作ストーリーは、著作権の切れた作品（イソップ寓話、アンデルセン、オスカー・ワイルド、O・ヘンリー）を、このツールのためにやさしい英語で書き直したものです。

    例文の追加

    1行に1文。英語チャンク / … || 日本語チャンク / … || 自然な訳 の形で貼り付けてください。英語と日本語のチャンクの数は同じにします。最後に || 表現メモ を足すと、意味の説明として表示されます（省略できます）。

    追加した文

    追加した文はこのブラウザに保存されます。「一覧」から1文ずつ削除できます。

    自由英文

    ニュース記事など、好きな英文を貼り付けてください。句読点・前置詞・接続詞・関係詞などを手がかりに自動でチャンクに分け、英語だけで流します（日本語訳は出ません）。
