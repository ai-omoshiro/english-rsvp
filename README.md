# English RSVP（直読直解トレーナー）

英文を意味のかたまり（チャンク）ごとに画面中央へ1つずつ表示し、各チャンクの直後に **英語の語順のままの日本語訳** を表示する学習ツールです。英語を前から順に理解する感覚（直読直解）を身につけることを目的にしています。

```
I like  →  私は好きです  →  basketball.  →  バスケットボールを  →  （全文と自然な訳）
```

**すぐに使う：https://ai-omoshiro.github.io/english-rsvp/** （無料・登録不要・スマホ対応）

- 外部ライブラリ・ネット接続・APIキーは使いません。オフラインで動きます。
- `index.html` をダブルクリックで開くだけで使えます（`file://` で動作）。パソコンなら、このリポジトリを「Code → Download ZIP」でダウンロードし、展開したフォルダの `index.html` を開けば、ネット接続なしでも使えます（ZIP は必ず展開してから開いてください）。
- パソコンとスマホ（iPhone の Safari など）の両方に対応しています。
- 例文・物語・単語帳は AI（Claude）の支援を受けて作成しています。不自然な点や誤りに気づいたら、[note（ai_omoshiro）](https://note.com/ai_omoshiro)のコメント欄で教えてください。

### ネイティブがよく使う表現

教科書にはあまり出てこないが、英語圏の人が日常や職場でよく使う言い回し（句動詞や決まり文句）を集めたレベルです。単語はやさしいのに意味が想像しにくい表現が多いので、**各文に「表現メモ」（意味と使い方の説明）** を付けています。表現メモは、文末の全文表示と「一覧」に出ます。短い文なので、何度もくり返し流して場面のイメージごと覚えるのに向いています。

| レベル | 文の数 | 入っている表現の例 |
| --- | --- | --- |
| よく使う表現・基礎 | 20 | `pick 人 up`（迎えに行く）、`run into`（偶然会う）、`Hang on a second.`（ちょっと待って）、`figure out`（わかる）、`It's up to you.`（あなた次第）、`My phone died.`（携帯の電池が切れた） |
| よく使う表現・日常 | 20 | `That makes sense.`（なるほど）、`sleep on it`（一晩考える）、`take a rain check`（また今度にする）、`I'm tied up.`（手が離せない）、`My bad.`（ごめん、自分のミス）、`play it by ear`（成り行きで決める） |
| よく使う表現・ビジネス | 20 | `walk 人 through`（順を追って説明する）、`touch base`（連絡を取り合う）、`circle back`（改めて戻る）、`loop 人 in`（話に加える）、`a ballpark figure`（概算）、`get the ball rolling`（始動させる） |

- 「全レベル」にも含まれます。
- 今までの例文のうち、`walk us through`、`follow up on`、`Please find attached`、`Do you mind if 〜?` のような分かりにくい表現を含む14文にも、表現メモを付けました（英文は変えていないので、苦手マークはそのままです）。

### 単語帳（フラッシュカード）

1枚に1つの語や短いかたまりを出し、パッパッと切り替えて覚える単語帳です。選ぶ基準は品詞ではなく **「目に浮かぶかどうか」** です。具体的な名詞のほか、動詞や形容詞も、場面が浮かぶ短いかたまりにしています。英語話者がよく使う組み合わせ（コロケーション）もここで覚えられます。

| カードの種類 | 例 |
| --- | --- |
| 具体的な名詞 | `colander`（ざる）、`faucet`（蛇口）、`receipt`（レシート） |
| 動作のかたまり（動詞＋名詞） | `do the dishes`（皿洗いをする）、`take out the trash`（ゴミを出す）、`catch a cold`（風邪をひく） |
| 形容詞＋名詞 | `a sore throat`（のどの痛み）、`a flat tire`（パンク）、`a crowded train`（満員電車） |

「教材を選ぶ」画面の「単語帳」タブでは、場面が5つの見出しに分かれています。見出しごとの「まとめて覚える」で、その見出しの場面を続けて覚えられます。1つの場面は22語で、初期設定の速さなら1周約70秒です。

| 見出し | 場面（各22語） |
| --- | --- |
| 家の中 | 🍳 台所／🛁 洗面所・お風呂・家の中／👕 服・身だしなみ／🔧 工具・DIY |
| 外出・旅行 | 🚦 街・交通／🚗 車・運転／🛒 お店・買い物／🍽️ レストラン・カフェ／✈️ 空港・飛行機／🏨 ホテル・旅行 |
| 人と体 | 🩺 体・病院／😊 表情・しぐさ・気持ち／🏃 スポーツ・ジム／☔ 天気・季節 |
| 仕事・お金・デジタル | 📎 オフィス・文房具／📱 スマホ・パソコン／💰 お金・銀行 |
| 和製英語 | 🔁 和製英語の言い換え（第1弾・第2弾） |

場面ごとの例：

- **服・身だしなみ**：`sleeve`（袖）、`a wrinkled shirt`（しわくちゃのシャツ）、`tie my shoes`（靴ひもを結ぶ）、`roll up my sleeves`（袖をまくる）
- **工具・DIY**：`screwdriver`（ドライバー）、`duct tape`（ガムテープ）、`a squeaky door`（きしむドア）、`put together furniture`（家具を組み立てる）
- **車・運転**：`turn signal`（ウインカー）、`buckle up`（シートベルトを締める）、`pull over`（車を寄せて止める）、`fill up the tank`（満タンにする）
- **レストラン・カフェ**：`to-go box`（持ち帰り用の容器）、`free refill`（おかわり無料）、`for here or to go`（店内か持ち帰りか）、`a sweet tooth`（甘いもの好き）
- **空港・飛行機**：`boarding pass`（搭乗券）、`carry-on`（機内持ち込みの手荷物）、`jet lag`（時差ぼけ）、`go through security`（保安検査を通る）
- **ホテル・旅行**：`front desk`（フロント）、`late checkout`（遅めのチェックアウト）、`store my luggage`（荷物を預ける）
- **表情・しぐさ・気持ち**：`shrug`（肩をすくめる）、`frown`（顔をしかめる）、`roll my eyes`（あきれて目を回す）、`butterflies in my stomach`（緊張でそわそわ）。動詞でも目に浮かび、日本語にない動作も多いので、物語を読むときにも役立ちます
- **スポーツ・ジム**：`treadmill`（ランニングマシン）、`work out`（筋トレする）、`break a sweat`（ひと汗かく）、`a close game`（接戦）
- **天気・季節**：`drizzle`（霧雨）、`puddle`（水たまり）、`humid`（蒸し暑い）、`get soaked`（びしょぬれになる）
- **スマホ・パソコン**：`notification`（通知）、`a cracked screen`（画面のひび割れ）、`The screen froze.`（画面が固まった）、`share my screen`（画面を共有する）
- **お金・銀行**：`withdraw cash`（現金を引き出す）、`loose change`（小銭）、`break a bill`（お札をくずす）
- **和製英語の言い換え**：コンセント→`outlet`、ホッチキス→`stapler`（第1弾）、ペットボトル→`plastic bottle`、アンケート→`survey`、リフォーム→`renovation`、ガムテープ→`duct tape` など（第2弾ほか）

- 各カードには、絵が浮かびやすいように **場面のひとこと（ヒント）** を付けています。絵文字は、ぴったり合う語にだけ付けています。
- **日→英**：単語帳を選ぶと、画面下に「日→英」ボタンが出ます（キーボードは `R`）。オンにすると、日本語（と絵文字・ヒント）を見て英語を思い出す練習になります。ヒントに英語が入っていて答えがわかってしまうカードでは、ヒントを表の面に出しません。
- 表示モードの意味は次のとおりです。
  - **英→日**：表（英語）→ 裏（答え）
  - **英語のみ**：英語だけを次々に流す
  - **英日同時**：最初から答えまで全部出す
  - **理解チェック**：表で止まり、タップで答えを出して「知ってた／あやしい／知らなかった」を選ぶ。苦手マークの付け外しは例文と同じ
- 表の面は「英語チャンク」、裏の面は「日本語チャンク」の表示時間を使います。画面右上には、1分あたりのカードの枚数を表示します。
- シャッフル・苦手だけ再生・読み上げ（英語が見えたときに読みます）・だんだん速くも使えます。
- 学習記録は「今日 ○文・○語」のように、読んだ文の数とめくったカードの枚数を分けて数えます。連続学習日数はどちらか一方でも数えます。

## 使い方

### 開き方

- **パソコン**：フォルダごとダウンロードし、`index.html` をダブルクリックしてブラウザで開きます。
- **iPhone / スマホ**：スマホの「ファイル」アプリから HTML を開くと、スクリプトが動かないことがあります。次のどれかの方法で Safari から開いてください。
  - GitHub Pages など、静的ファイルを置ける場所に4つのファイルを置き、その URL を Safari で開く
  - パソコンでこのフォルダに移動して `python3 -m http.server 8000` を実行し、同じ Wi-Fi のスマホから `http://（パソコンのIPアドレス）:8000/` を開く
  - Safari の共有メニューから「ホーム画面に追加」すると、アプリのように起動できます

### 表示モード

- **英→日 交互**：英語チャンクと日本語チャンクを交互に表示します（基本のモード）。
- **英語のみ**：訳を出さずに英語チャンクだけを表示します。文末の全文表示で訳を確認できます。
- **英日同時**：英語チャンクの下に日本語チャンクを並べて表示します。
- **理解チェック**：自分のペースで進めるモードです。
  1. 英語チャンクを表示したまま止まります。意味を考えてから画面をタップ（または `Space`）すると、下に日本語チャンクが出ます。
  2. もう一度タップすると次のチャンクへ進みます。
  3. 文末で「わかった／あやしい／わからなかった」を選ぶと、次の文へ進みます。
  - 「あやしい」「わからなかった」を選んだ文には、自動で苦手マークが付きます。
  - 苦手マークの付いた文で「わかった」が **2回続く** と、マークが自動で外れます（途中で「あやしい」「わからなかった」を選ぶと数え直し）。
  - 「苦手だけ再生」と組み合わせると、苦手な文が減っていくのを確かめながら復習できます。

### 設定（右上の「設定」）

- **表示時間**：英語チャンク・日本語チャンク・文末の全文表示の時間をスライダーで変えられます（英日同時モードは英語＋日本語の時間を足した長さ）。
- **チャンクの大きさ**：「標準」「2つずつ」「3つずつ」。隣り合うチャンクを英語・日本語とも同じ単位でつなげて表示します。慣れてきたら大きな単位で読む練習に使えます。例文のデータは変わりません。
- **だんだん速く**：オンにすると、文を1つ読み終えるたびに英語の表示時間を少しずつ短くします。
  - 「1文ごとに短くする割合」（1〜10%）と「英語の表示時間の下限」（0.2〜2.0秒）を変えられます。
  - 「最初の速さに戻す」で、英語の表示時間を設定した値に戻します。英語の表示時間のスライダーを動かしたときや、オンにし直したときも元に戻ります。
  - 速くした状態は保存しません（ページを開き直すと設定した表示時間から始まります）。
- **読み上げ**：ブラウザ標準の音声読み上げ（Web Speech API）で英語チャンクを読みます。読み上げ中は読み終わるまで次に進みません。文末に英文全体を読む設定や、読む速さも変えられます。
  - **声**：その端末で使える英語の音声の一覧から選べます（「自動」はアメリカ英語の声を優先して選びます）。「試しに聞く」で確認できます。選んだ声は保存され、その声がない端末では自動で選びます。
  - 読み上げの声はブラウザや OS に入っている英語音声を使います。iPhone で音が出ないときは、音量やサイレントモードを確認してください。一覧が空のときは、少し待ってから設定を開き直してください（声の一覧が遅れて届くブラウザがあります）。
- **見た目**：文字の大きさ（小・中・大）、テーマ（自動・ライト・ダーク）。長い文は画面に収まるよう自動で文字が小さくなります。

### ストーリーの読み方

1. 左上のボタンで「教材を選ぶ」画面を開き、「ストーリー」タブから話を選びます。「すべてのストーリー」は全部の話を、各見出しの「まとめて読む」はその難易度の話を、続けて読みます。
2. 再生すると、まず題名が出て、そのあと1文目から順番に流れます。シャッフルは使えません。
3. 最後の文まで読むと「おしまい」と出て止まります。もう一度タップすると最初から読めます。

- 初めは「設定 → ストーリーでは文末の全文と訳を出さずに、続けて読む」がオンになっています。文が切れ目なく次々に流れるので、話の流れを追いながら場面を思い浮かべる練習に向いています。
- 1文ごとに全文と自然な訳を確かめたいときはオフにしてください。オンのままでも、前後の文へ移動したときの停止中の画面や「一覧」で、全文と自然な訳を見られます。
- 「英語のみ」にすると訳なしで物語を読み進められます。「理解チェック」にすると、題名の画面でもタップを待ちます。
- 画面左上には話の題名と、その話の何文目かを表示します。
- 苦手マーク・「苦手だけ再生」・読み上げ・チャンクの大きさ・だんだん速くも使えます。

### 自由英文モード（右上の「文章」）

ニュース記事など、好きな英文を貼り付けて英語だけで流すモードです。AI やネット接続は使わず、ブラウザの中だけで処理します。

1. 「文章」を開き、英文を貼り付けます。
2. 「分け方を確認」で、どのようにチャンクに分かれるかを確認できます。
3. 「チャンクに分けて再生」を押すと再生が始まります。最後の文まで読むと止まります。
4. 元の例文に戻るときは、表示エリア左上の「終了」を押すか、「教材を選ぶ」画面で教材を選び直します。

- 文の区切りは `.` `!` `?` で判断します（`Mr.` `Dr.` `U.S.` `e.g.` などの略語では区切りません）。
- チャンクは、句読点（`,` `;` `:` `—`）の後や、前置詞（in, on, at, with …）・接続詞（and, but, because, although …）・関係詞や疑問詞（who, which, that, where, how …）の前で区切り、長くなりすぎたら語数の目安で区切ります。目安は「4語／6語／8語まで」から選べます。
- 機械的に分けるので、意味のかたまりと合わないこともあります。
- 表示モードは「英語のみ」に固定され、苦手マークや理解チェックは使えません。読み上げ・チャンクの大きさ・だんだん速くは使えます。
- 「文末に英文全体を表示する」をオフにすると、文末の全文表示を飛ばして続けて流します。
- 貼り付けた英文は保存され、次に開いたときも入力欄に残ります。

### 保存されるもの

設定・苦手マーク・追加した文・最後に見ていた文・理解チェックの記録・学習記録・自由英文に貼り付けた英文は、ブラウザの `localStorage` に保存されます。

| キー | 内容 |
| --- | --- |
| `englishRsvp.settings.v1` | 設定（以前の版の設定もそのまま読み込めます） |
| `englishRsvp.weak.v1` | 苦手マーク |
| `englishRsvp.custom.v1` | 追加した文 |
| `englishRsvp.check.v1` | 理解チェックで「わかった」が続いた回数（新規） |
| `englishRsvp.stats.v1` | 日付ごとの読んだ文の数と、単語帳のカードの枚数（400日より前の記録は自動で消します） |
| `englishRsvp.free.v1` | 自由英文に貼り付けた英文（新規） |

- 保存はブラウザごと・開き方（`file://` か URL か）ごとに別々です。
- ブラウザの履歴やサイトデータを消すと、保存した内容も消えます。追加した文は「例文の追加」→「テキストで書き出す」でテキストにしてバックアップできます。

## 例文の追加方法

### 方法1：画面から貼り付ける

1. 右上の「追加」を開きます。
2. 下の「テキスト形式」で書いた文を、1行1文で貼り付けます（何行でもまとめて貼り付けられます）。
3. レベルを選び「追加する」を押します。

形式に誤りがある行は、理由と一緒に表示され、入力欄に残るので直してもう一度追加できます。同じ英文がすでにある場合は追加されません。追加した文は「教材を選ぶ」画面の「例文」タブにある「追加した文」でまとめて再生でき、「一覧」から1文ずつ削除できます。

### 方法2：`sentences.js` を直接編集する

`sentences.js` の各レベルの `text:` の中に、同じ形式で1行ずつ書き足します。全員に配りたい例文はこちらに書くと便利です。

```js
  {
    level: "daily",   // basic（基礎） / daily（日常会話） / business（ビジネス） / advanced（上級） / bizadv（ビジネス上級）
    text: `
Could you tell me / the way / to the nearest station? || 教えていただけますか / 道を / 最寄り駅までの || 最寄り駅までの道を教えていただけますか。
（ここに1行ずつ追加）
`
  },
```

> 英文を書き換えると、その文の苦手マークは外れます（英文から文の ID を作っているため）。

### ストーリーを足すとき

`sentences.js` のいちばん下に、次のような固まりを足します。文の形式は短文と同じで、上から順番に再生されます。足した話は、「教材を選ぶ」画面の「ストーリー」タブに自動で出ます。

```js
  {
    level: "story",
    story: "my-story",           // 英数字とハイフンの ID（ほかの話と重ならないように）
    title: "My Story",           // 英語の題名
    titleJa: "わたしの物語",      // 日本語の題名
    group: "名作・中級",          // メニューでのまとまり（省略すると「オリジナル」）
    note: "中級・約12文",          // 難しさなど（題名の画面に出ます）
    source: "グリム童話",          // 原作（省略可。題名の画面に出ます）
    text: `
Once upon a time, / there lived a girl / who loved the sea. || 昔むかし / 一人の少女が住んでいました / 海が大好きな || 昔むかし、海が大好きな少女が住んでいました。
（ここに1行ずつ続ける）
`
  },
```

- 前の固まりの最後の `}` のあとに `,` を付けてから足してください。
- 同じ英文はひとつしか登録されないので、話の中で同じ文をくり返さないようにします（「He smiled.」のような短い文は、ほかの話や例文と重なりやすいので注意）。

### 単語帳に語を足すとき

`words.js` の場面の `text:` の中に、1行1枚で書き足します。新しい場面も、同じ形の固まり（`scene`・`category`・`title`・`emoji`・`desc`・`text`）を足せば「単語帳」タブに自動で出ます。`category` に今ある見出し（「家の中」など）を書けばその下に並び、新しい名前を書けば見出しが増えます。

```
英語 || 日本語 || 場面のひとこと（ヒント） || 絵文字
colander || ざる || パスタや野菜の水を切る、穴のあいた器
faucet || 蛇口 || 水が出るところ。イギリスでは tap || 🚰
```

- ヒントと絵文字は省略できます。
- 選ぶときは「目に浮かぶか」を基準にしてください。抽象的な語（opportunity など）は、単語帳より例文で覚えるほうが向いています。

## テキスト形式の説明

```
英語チャンク / 英語チャンク / … || 日本語チャンク / 日本語チャンク / … || 自然な日本語訳
英語チャンク / 英語チャンク / … || 日本語チャンク / 日本語チャンク / … || 自然な日本語訳 || 表現メモ
```

4つ目の「表現メモ」は省略できます。書いた場合は、文末の全文表示と一覧に、意味の説明として表示されます。

例：

```
I like / basketball || 私は好きです / バスケットボールを || 私はバスケットボールが好きです
I went to the station / to meet my friend / yesterday. || 私は行きました 駅へ / 友達に会うために / 昨日 || 私は昨日、友達に会うために駅へ行きました。
Hang on a second. / I'll be right back. || ちょっと待って / すぐ戻るね || ちょっと待ってて、すぐ戻るから。 || Hang on (a second).：ちょっと待って（Wait. より柔らかく、よく使う）
```

ルール：

- **1行 = 1文**。
- `||` で「英語チャンク」「日本語チャンク」「自然な訳」の **3つ** に区切ります。表現メモを付けるときは **4つ** にします。
- 表現メモに複数の表現を書くときは `／`（全角スラッシュ）で区切ると、1行ずつ表示されます。
- チャンクは `/` で区切ります。
- **英語チャンクと日本語チャンクの数は同じ** にします（1番目の英語に1番目の日本語、2番目の英語に2番目の日本語…が対応します）。
- 日本語チャンクは **英語の語順のまま** に並べ、助詞（は・を・に・で・へ など）を付けて、そのチャンクだけでも意味が取れるようにします。
- 空行と、`#` で始まる行は無視されます（メモに使えます）。
- 全角の `／` や `｜｜` も使えます。英文の中に `/` を含めることはできません（`and/or` は `and or` などに書き換えてください）。

## 他のAIに例文を作らせるときのお願い文の例

下の文をそのまま ChatGPT や Claude などに貼り付け、`【 】` の部分を書き換えて使ってください。出てきた行を「追加」画面に貼り付ければ、そのまま使えます。

```
英語の「直読直解」練習用の例文を作ってください。

# 条件
- テーマ：【例：海外出張でのホテルや空港での会話】
- レベル：【例：中学〜高校レベルの文法、1文10〜18語くらい】
- 文の数：【例：15文】

# 出力形式（厳守）
- 1行に1文。説明や番号、空行、コードブロックは付けず、次の形式の行だけを出力してください。
  英語チャンク / 英語チャンク / … || 日本語チャンク / 日本語チャンク / … || 自然な日本語訳
- 英文を意味のかたまり（チャンク）ごとに「/」で区切ってください。1チャンクは1〜5語くらいを目安にします。
- 日本語チャンクは、英語チャンクと同じ数・同じ順番で並べてください。英語の語順のまま訳し、日本語として自然な語順に並べ替えないでください。
- 日本語チャンクには助詞（は・を・に・で・へ など）を付けて、そのチャンクだけでも意味が取れるようにしてください。
- 最後の「自然な日本語訳」は、普通の日本語の語順で書いてください。
- 英文の中に「/」や「||」を使わないでください。

# 例
I like / basketball. || 私は好きです / バスケットボールを || 私はバスケットボールが好きです。
I went to the station / to meet my friend / yesterday. || 私は行きました 駅へ / 友達に会うために / 昨日 || 私は昨日、友達に会うために駅へ行きました。
```

出力後に「英語チャンクと日本語チャンクの数がすべての行で同じか確認して、違う行があれば直してください」と頼むと、エラーが減ります。

ネイティブがよく使う表現を集めたいときは、条件と出力形式を次のように書き換えます。

```
# 条件
- テーマ：【例：レストランやカフェで】
- 内容：教科書にはあまり出てこないが、英語圏の人が日常でよく使う言い回し（句動詞・決まり文句）を1文に1つ入れる
- 長さ：1文5〜12語くらいの短い文
- 文の数：【例：20文】

# 出力形式（厳守）
  英語チャンク / … || 日本語チャンク / … || 自然な日本語訳 || 表現メモ
- 表現メモには「表現：意味（使う場面やニュアンス）」を書いてください。例：sleep on it：一晩じっくり考える
- 表現が2つあるときは「／」で区切ってください。
（ほかのルールは上のお願い文と同じ）
```

ストーリーを作らせるときは、上のお願い文の「条件」を次のように書き換え、「1行に1文、話の順番どおりに出力してください」と付け加えます。出てきた行を、上の「ストーリーを足すとき」の `text:` の中に貼り付けます。

```
- テーマ：【例：小さな港町を舞台にした、少し不思議で心温まる話】
- レベル：【例：中級。1文12〜25語。情景が目に浮かぶような描写を多めに】
- 文の数：【例：15文。起承転結があり、最後の文で話が締まるように】
```

上級向けの文を作らせるときは、条件を次のように書き換えると「上級」「ビジネス上級」と同じくらいの難しさになります。

```
- テーマ：【例：製造業での AI・データ活用をめぐる会議と交渉】
- レベル：上級。1文20〜35語。関係詞の重なり、分詞構文、倒置、仮定法、挿入句のどれかを必ず含める
- 文の数：【例：10文】
```

## データとプライバシー

- 設定・苦手マーク・学習記録・追加した文は、使っている端末のブラウザ（`localStorage`）の中だけに保存されます。このツールが外部に送信することはありません。アクセス解析や広告も使っていません。
- 読み上げはブラウザに入っている音声（Web Speech API）を使います。ブラウザによっては（Chrome の「Google」の声など）、読み上げる英文がブラウザの提供元のサーバーで処理されることがあります。
- Web版は GitHub Pages で配信しています。ページの配信にともなう記録は GitHub が管理しています。
